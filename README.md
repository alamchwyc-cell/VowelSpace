# VowelSpace：二语英语元音的声学诊断

> 31 位说话者、同一批朗读材料，比较六种母语背景的二语学习者与英语母语者的元音声学特征，
> 检验"母语迁移导致元音范畴合并"这一假设，并把结论做成可解释的发音诊断工具。

## 核心结论（一句话）

**`/ɪ/–/iː/` 的范畴合并是二语学习的普遍困难，而不是某种母语特有的迁移。**
24 位学习者与 7 位母语者朗读相同的 250 个句子，学习者的 `/ɪ/–/iː/` 距离
仅为母语者的 34%（d = −2.43）；但**普通话与其他母语背景之间没有差异**（p = 0.73）。

## 数据

| 组 | 说话人 | 句数 |
|---|---|---|
| 英语母语者 | 7（CMU ARCTIC） | 1,750 |
| 普通话 | 5（BWC/LXC/NCC/TNI/TXHC） | 1,250 |
| 阿拉伯语 | 4 | 1,000 |
| 印地语 | 4 | 1,000 |
| 韩语 | 4 | 1,000 |
| 西班牙语 | 4 | 1,000 |
| 越南语 | 3 | 750 |

共 **31 位说话者、7,750 条录音、78,293 个元音 token**。所有说话人朗读
**完全相同的 250 个提示句**（arctic_a0001–a0250）。L2 数据取自官方
L2-ARCTIC v5.0（自带音素级 TextGrid 标注）。

## 主要结果

**1. 整体指标接近显著，局部指标效应极大**

| 指标 | 学习者 | 母语者 | 效应量 |
|---|---|---|---|
| 元音空间面积（归一化 Bark²） | 4.13 | 5.03 | d = −1.11，p = 0.095 |
| **/ɑː/–/ʌ/ 距离** | 0.42 | 0.99 | **d = −3.83** |
| **/ɪ/–/iː/ 距离** | 0.41 | 1.19 | **d = −2.43** |
| /ʊ/–/uː/ 距离 | 0.44 | 0.78 | d = −1.17 |

**2. 跨母语比较：不是普通话特有**

| 组 | /ɪ/–/iː/ 距离 |
|---|---|
| 英语母语者 | 1.19 |
| 印地语 | 0.82 |
| 阿拉伯语 | 0.81 |
| 韩语 | 0.41 |
| **普通话** | **0.41** |
| 西班牙语 | 0.24 |
| 越南语 | 0.16 |

- 七组之间有显著差异（Kruskal–Wallis p = 0.002）；
- **但普通话与其他 L2 组无差异**（p = 0.73）；
- 西班牙语、越南语的合并程度**比普通话更强**。

> 这推翻了"普通话没有松紧对立 → 母语迁移"的简单解释。
> 该困难在多种母语背景中普遍存在，普通话只是其中之一。

**3. 时长线索：趋势，但未达显著**

| 指标 | 学习者 | 母语者 | 效应量 |
|---|---|---|---|
| `/iː/` 与 `/ɪ/` 时长比（仅重读元音） | 1.13 | 1.27 | d = −1.06，p = 0.074 |

> 早期用未按重音过滤的数据得到 d = −2.94（p = 0.008），属口径错误；
> 修正后效应缩小为趋势。**报告时以本行为准。**

**4. 语速**

| 指标 | 学习者 | 母语者 | 效应量 |
|---|---|---|---|
| 语速（音节/秒） | 2.89 | 3.64 | d = −2.51，p = 0.005 |

## 发音诊断工具

```bash
python3 src/diagnose.py --wav my.wav --text "the text you read"
```

输出每个元音相对母语者参照分布的偏离度（马氏距离 + χ² 百分位）、
松紧时长检查与教学建议。网页版：`streamlit run src/app.py`。

## 方法与严谨性

| 设计 | 排除的混淆 |
|---|---|
| 所有说话人读同一批 250 句 | 文本、音素环境 |
| Bark 标度 + Lobanov 归一化 | 声道长度、性别 |
| 混合效应模型（说话人随机截距） | 同一人多条样本的伪重复 |
| 置换检验（说话人层面） | 正态假设 |
| 说话人为分析单位做组间比较 | token 数差异造成的假阳性 |
| 效应量与置信区间 | 只报 p 值 |
| 报告负结果（擦音模块未通过验证） | 选择性报告 |

## 局限

- 每个 L2 组仅 3–5 位说话人，组间比较功效有限；
- 朗读语料，非自然口语；
- 单次短录音的归一化估计不稳定（`shrinkage.py` 给出解决方案）；
- 只覆盖元音与韵律，未覆盖辅音。
