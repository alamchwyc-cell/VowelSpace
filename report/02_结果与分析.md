# 结果与分析

> 数据：31 位说话者（24 位二语学习者 + 7 位英语母语者），7,750 条录音，
> 78,293 个元音 token。所有说话者朗读**完全相同的 250 个提示句**
> （arctic_a0001–a0250）。L2 数据取自官方 L2-ARCTIC v5.0（自带音素级 TextGrid）。

---

## 0. 两次口径修正（先说清楚）

本项目的数字经过两次修正，都记录在此，便于核查。

**修正一：归一化顺序错误**

初版把 Lobanov 归一化作用在 Hz 上，却用**未归一化**的 Bark 值计算面积与距离，
结论受说话人声道长度（尤其性别）污染。修正为：

```
Hz --(Bark)--> 感知标度 --(Lobanov)--> 归一化坐标
```

修正后元音空间面积的方向发生反转（由"学习者更大"变为"学习者更小"）。

**修正二：时长统计包含了非重读元音**

初版时长比用全部元音计算（含 IH0 等弱化元音），得出 d = −2.94（p = 0.008）。
但共振峰分析只用了重读元音，两者口径不一致，且母语者弱化更多，会人为拉大组间差异。

按重读元音重算后：**d = −1.06，p = 0.074（不显著）**。
**本报告以修正后的数字为准**，早期数字作废。

## 1. 元音空间面积：趋势但未达显著

| 组 | n | 平均 VSA（归一化 Bark²） |
|---|---|---|
| 中国学习者 | 5 | 4.13 |
| 英语母语者 | 7 | 5.03 |

- 差值 −0.90，置换检验 **p = 0.095**，Cohen's d = **−1.11**。

方向与"元音空间收缩"假设一致，效应量中等偏大，但**未达 0.05 显著性**。

## 2. 元音对距离：局部效应极强

| 元音对 | 学习者 | 母语者 | 差值 | Cohen's d |
|---|---|---|---|---|
| **/ɑː/–/ʌ/** | 0.42 | 0.99 | −0.57 | **−3.83** |
| **/ɪ/–/iː/** | 0.41 | 1.19 | −0.79 | **−2.43** |
| /ʊ/–/uː/ | 0.44 | 0.78 | −0.35 | −1.17 |
| /æ/–/e/ | 0.56 | 0.41 | +0.15 | 0.69 |

整体指标不显著，局部指标效应极大——这一对比本身就是结论：
**用"元音空间面积"做二语语音研究，会漏掉真实效应。**

## 3. 跨母语比较：不是普通话特有（核心结果）

七组说话者（六种 L2 母语 + 英语母语）的 `/ɪ/–/iː/` 距离：

| 组 | n | 均值 |
|---|---|---|
| 英语母语者 | 7 | **1.19** |
| 印地语 | 4 | 0.82 |
| 阿拉伯语 | 4 | 0.81 |
| 韩语 | 4 | 0.41 |
| **普通话** | **5** | **0.41** |
| 西班牙语 | 4 | 0.24 |
| 越南语 | 3 | 0.16 |

| 检验 | 结果 |
|---|---|
| 七组整体差异（Kruskal–Wallis） | **H = 20.82, p = 0.002** |
| 普通话 vs 英语母语者 | d = −2.43, p = 0.005 |
| 其他 L2 vs 英语母语者 | d = −1.96, p < 0.001 |
| **普通话 vs 其他 L2** | **d = −0.29, p = 0.73（无差异）** |
| 仅六组 L2 之间 | H = 12.75, p = 0.026 |

**结论：`/ɪ/–/iː/` 的范畴合并是二语学习的普遍困难，不是某一母语特有的迁移。**

- 西班牙语、越南语的合并程度**比普通话更强**；
- 普通话在 L2 组中处于中间位置；
- 各组之间确实存在显著差异（p = 0.026），说明母语背景有调节作用，
  但不是"普通话没有松紧对立"这一条能解释的。

**这一结果推翻了本项目最初的理论假设**，是本次扩容最重要的产出。

## 4. 时长与语速

**松紧时长比**（仅重读元音）：

| 指标 | 学习者 | 母语者 | 效应量 |
|---|---|---|---|
| `/iː/` 与 `/ɪ/` 的时长比 | 1.13 | 1.27 | d = −1.06，**p = 0.074** |

方向上学习者确实拉得不够长，但**未达显著**。按母语背景看：

| 组 | 时长比 |
|---|---|
| 印地语 | 1.33 |
| 阿拉伯语 | 1.31 |
| 英语母语者 | 1.27 |
| 韩语 | 1.16 |
| 越南语 | 1.14 |
| 普通话 | 1.13 |
| 西班牙语 | 1.03 |

阿拉伯语、印地语几乎保持了母语者的时长对比，而普通话、韩语、西班牙语没有。
但组间差异未达显著（Mandarin vs 其他 L2，p = 0.32）。

**语速**：

| 指标 | 学习者 | 母语者 | 效应量 |
|---|---|---|---|
| 音节/秒 | 2.89 | 3.64 | d = −2.51，**p = 0.005** |

## 5. 混合效应模型

模型：`F1 ~ group × vowel + gender + (1|speaker)`（普通话 vs 母语者，16,586 个 token）。

组别主效应不显著，但多个元音的组×元音交互项显著——说明差异是**局部的**。
完整系数见 `results/mixed_coefs.csv`。

## 6. 可懂度：ASR 词错率

每位说话人取 40 句，用 wav2vec2-base-960h 识别，计算词错率。

| 组 | n | 平均 WER |
|---|---|---|
| 中国学习者 | 5 | **24.0%** |
| 英语母语者 | 7 | **7.7%** |

**元音偏离度与 WER 的相关性**：

| 样本 | Spearman ρ | p |
|---|---|---|
| 全部 12 人 | **0.937** | < 0.001 |
| 仅母语者 7 人 | **1.000** | < 0.001 |

组内同样完美秩相关，说明这不是"两组不同"造成的假象：即使母语者内部，
元音越偏离的人被 ASR 听错的也越多。

## 7. 小样本鲁棒归一化（方法学尝试）

**问题**：标准 Lobanov 依赖说话人自身的均值/方差，短录音时估计噪声大。
实测中同一位说话人 12 句给出时长比 1.60，250 句给出 1.14，结论相反。

**方法**：把说话人均值/方差向同性别母语者总体收缩（经验贝叶斯）：

```
μ̂ = (n·μ_s + k·μ_pop) / (n + k)
```

**结果**（以 `/ɪ/–/iː/` 距离的稳定性为指标，重复抽样 40 次）：

| token 数 | 标准 Lobanov 的偏差 | 收缩法偏差 | 改进 |
|---|---|---|---|
| 10 | 0.409 | 0.380 | **7.1%** |
| 20 | 0.324 | 0.311 | 3.9% |
| 30 | 0.266 | 0.260 | 2.2% |
| 50 | 0.199 | 0.195 | 1.8% |

**结论：有改进，但幅度有限（4–7%）。** 收缩强度 k 在 10–200 之间变化时改进稳定在 4% 左右。

原因推测：先验取自母语者，而学习者系统性地偏离母语者分布，收缩会同时拉入偏差。
**这是一个诚实的负结果**，不宣称"解决了小样本问题"。

## 8. 负结果：擦音频谱矩

`/θ/` `/ð/` 的频谱矩曾实现并分析，三条独立检验均未通过：

| 检查 | 结果 |
|---|---|
| 组间差异 | p = 0.25 |
| ASR 在含 th 词上的错误率 | 与非 th 词无差异 |
| 频谱重心 vs th 词错误率 | ρ = −0.04 |
| 测量稳定性 | 同一说话人 `/θ/` 与 `/f/` 的重心关系都不稳定 |

故未纳入诊断工具，也未纳入图集。

## 9. 局限

1. 每个 L2 组仅 3–5 位说话人，组间比较功效有限；
2. 朗读语料，与自然口语存在差异；
3. 单次短录音的归一化估计不稳定（见第 7 节）；
4. 未覆盖辅音与语调；
5. 未做教学干预，因此只能说"诊断有效"，不能说"能提高发音"。
