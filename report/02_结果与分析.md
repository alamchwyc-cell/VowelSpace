# 结果与分析

> 数据：L2-ARCTIC 普通话 3 人（750 条）+ CMU ARCTIC 母语 7 人（1750 条），
> 同一批 250 句。MFA 音素级对齐后提取 13,507 个元音 token（清洗后 13,490）。

## 0. 一个必须先纠正的处理

初版分析把 Lobanov 归一化作用在 Hz 上，却仍用**未归一化**的 Bark 值计算面积与距离，
导致结论受说话人声道长度（尤其性别）污染。现已修正为：

```
Hz --(Bark)--> 感知标度 --(Lobanov)--> 归一化坐标
所有几何量（面积、距离）都在归一化 Bark 上计算。
```

修正后元音空间面积的方向发生反转，但元音对距离的结论不变且更强。

## 1. 元音空间面积（H1）

| 组 | 说话人 | 平均 VSA (归一化 Bark²) |
|---|---|---|
| 中国学习者 | LXC 4.66 / NCC 4.35 / BWC 4.06 | **4.36** |
| 英语母语者 | clb 6.16 / slt 6.13 / bdl 5.38 / rms 5.21 / ksp 4.93 / jmk 4.04 / awb 3.45 | **5.04** |

- 组间差值 **−0.69**（学习者更小），置换检验 **p = 0.311**，Cohen's d = **−0.77**。

**结论：方向与假设一致，但未达显著。** 效应量已达中等偏大（0.77），
但在 n=3 vs 7 的水平上，置换检验最低可及 p 约为 1/120，功效不足。

值得注意：母语者组内差异极大（3.45–6.16），说明该指标对个体差异非常敏感。

## 2. 元音对距离（H2）

| 元音对 | 学习者 | 母语者 | 差值 | Cohen's d | 判定 |
|---|---|---|---|---|---|
| **ɪ–iː** | **0.27** | **1.20** | −0.93 | **−3.03** | **强支持** |
| **ɑː–ʌ** | **0.42** | **1.00** | −0.58 | **−4.36** | **强支持** |
| ʊ–uː | 0.54 | 0.78 | −0.24 | −0.82 | 趋势一致 |
| æ–e | 0.55 | 0.41 | +0.14 | 0.64 | 方向相反 |
| e–ɪ | 1.69 | 1.13 | +0.56 | 2.46 | 伴随现象 |

**结论：H2 强支持，效应量极大。**

- `/ɪ/–/iː/`：d = **−3.03**。学习者的这两个元音在归一化声学空间里几乎重合。
- `/ɑː/–/ʌ/`：d = **−4.36**，比预期更强。普通话只有一个低元音 /a/，
  学习者难以区分英语的两个低元音。
- `e–ɪ` 距离反而变大（d = +2.46）不是独立现象，而是 `/ɪ/` 被拉向 `/iː/` 后的连带结果。

## 3. 混合效应模型

模型：`F1(Hz) ~ group × vowel + gender + (1|speaker)`，13,490 个 token，
说话人为随机截距（原始 Hz，不用归一化值——归一化已把说话人均值归零，随机截距会退化）。

| 项 | 系数 (Hz) | p |
|---|---|---|
| group（Native vs L2，主效应） | −35.2 | **0.432（不显著）** |
| × ɪ | **+76.0** | < 0.001 |
| × æ | **−52.6** | < 0.001 |
| × ɑː | **+62.2** | < 0.001 |
| × ʌ | **−63.8** | < 0.001 |
| × ɔː | **+40.2** | < 0.001 |
| × ʊ | +33.1 | 0.015 |
| × iː | +0.8 | 0.908 |
| × uː | +7.3 | 0.400 |
| × ɜː | +17.5 | 0.114 |

**全篇最关键的一点**：

> **组别主效应完全不显著（p = 0.43），但 6 个元音的组×元音交互项显著。**

中国学习者的元音系统**不是整体偏移，也不是整体压缩**，而是**特定元音的重新定位**。
整体性指标（元音空间面积）必然检测不到，这正好解释了 H1。

F2 模型给出同样结构：`uː` 交互项 +338.6 Hz（p < 0.001）、`iː` +70.6 Hz（p < 0.001）。


## 3.5 可懂度：用 ASR 词错率作代理

真人听辨成本高。这里用语音识别器作为"挑剔的听者"：若 ASR 听错，
说明该发音在声学上偏离标准英语的典型分布。

设置：每位说话人随机取 40 句，wav2vec2-base-960h 识别，计算词错率（WER）。

| 组 | 平均 WER |
|---|---|
| 中国学习者 | **29.4%** |
| 英语母语者 | **7.7%** |

**元音偏离度与 WER 的相关性**：

| 样本 | Spearman ρ | p |
|---|---|---|
| 全部 10 人 | **0.988** | < 0.001 |
| 仅母语者 7 人 | **1.000** | < 0.001 |
| 去掉 ksp（异常点） | 0.983 | < 0.001 |

**组内也是完美秩相关**，说明这不是"两组不同"造成的假象：
即使在母语者内部，元音越偏离标准分布的人，被 ASR 听错的也越多（ksp 是典型例子：
元音偏离最大，WER 也最高）。

**意义**：这把"声学偏差"和"实际可懂度"连了起来。发音诊断工具给出的分数，
不只是"和母语者不像"，而是与"别人能不能听懂"相关。

## 4. 综合解释

| 现象 | 解释 |
|---|---|
| 面积差异不显著 | 错误是**局部的**，被整体指标平均掉了 |
| `/ɪ/–/iː/` 几乎重合 | 普通话无松/紧元音对立，学习者用同一范畴覆盖两者 |
| `/ɑː/–/ʌ/` 接近 | 普通话只有一个低元音 /a/ |
| `e–ɪ` 距离变大 | `/ɪ/` 移向 `/iː/` 的连带效应 |
| `/ʊ/–/uː/` 趋势一致 | 后元音也有合并倾向，但较弱 |

**核心结论**：母语迁移不是"整体发音空间变小"，而是**特定音位范畴的合并**。
方法上意味着：用元音空间面积做二语语音研究，可能漏掉真实效应。

## 5. 局限

1. **说话人样本量小**（3 vs 7）。说话人层面检验功效有限；主结论依赖 token 级混合模型。
2. **只有 3 位普通话母语者**。公开镜像（NathanRoll/l2-arctic-dataset）中仅含
   BWC/LXC/NCC 三位；官方语料的 TNI、TXHC 未包含在内，且镜像把 TNI 误标为 Hindi。
3. **朗读语料**，与自然口语存在差异。
4. 未控制语速、重音位置、句末位置。
