# 研究设计

> 项目：中国英语学习者元音空间的声学分析
> 阶段：预研 / 数据与流程验证

## 1. 研究问题

中国英语学习者的英语元音发音，与英语母语者相比，在声学空间上有什么系统性差异？

## 2. 假设

| 编号 | 假设 | 判定标准（事先声明） |
|---|---|---|
| H1 | 归一化后，学习者元音空间面积小于母语者 | 面积差 ≥ 15%，且置换检验 p < 0.05 |
| H2 | 特定元音对距离更小（混音） | 至少 2 对达到 Cohen's d > 0.8 |
| H3 | 学习者基频范围更窄 | 待定（可选） |

**H1 若不成立**：说明"整体面积"不敏感，转而报告 H2 的局部距离，并在讨论中说明
指标选择对结论的影响——这本身是一个方法学发现。

## 3. 数据与对照设计

| 语料 | 说话人 | 数量 |
|---|---|---|
| L2-ARCTIC（普通话） | BWC(男)、LXC(女)、NCC(女) | 750 条 |
| CMU ARCTIC | bdl、slt、clb、rms、jmk、awb、ksp | 1750 条 |

**关键**：两组朗读**完全相同的 250 个提示句**。因此文本内容、音素环境、
句子长度全部被控制，组间差异只能来自说话人本身。

## 4. 为什么这个设计严密

### 4.1 必须做的三件事

1. **音素级强制对齐**：只知道"这句话里有 /ɪ/"没有用，必须知道它出现在第几秒。
   用 Montreal Forced Aligner（带 CMU 发音词典），得到每个音素的起止时间。

2. **说话人归一化**：女性共振峰系统性高于男性约 15–20%，比母语差异还大。
   不归一化，测出来的是性别差异。采用 Lobanov（z-score）为主，
   Nearey（对数均值）作稳健性检验。

3. **混合效应模型**：同一说话人贡献 250 条发音，彼此不独立。
   若按 token 做 t 检验，等于把 11 人当成 2750 个独立个体，p 值严重虚低。

### 4.2 必须做的对照

| 对照 | 作用 |
|---|---|
| 同一批句子 | 排除文本难度、音素环境 |
| 双归一化方法 | 排除结论对方法的依赖 |
| 置换检验（说话人层面） | 不依赖正态假设 |
| 组内个体差异 | 作为"差异下界"的参照 |

### 4.3 已知限制（必须在报告中写明）

- 学习者只有 3 人，说话人层面的统计功效有限；因此主分析放在 token 级的
  混合效应模型上，说话人级指标（VSA）只作描述与辅助检验。
- CMU ARCTIC 是"朗读"语料，与自然口语存在差异。
- 只取重读元音（stress 1/2），非重读元音弱化后不代表目标音位。

## 5. 技术流程

```
音频 (16 kHz)
  → MFA 音素级对齐 (TextGrid)
  → 元音中段 50% 窗口，LPC 估计 F1/F2（中位数）
  → 异常值剔除（说话人内 1.5×IQR）
  → Lobanov / Nearey 归一化
  → Hz → Bark
  → 元音空间面积（凸包）/ 元音对距离
  → 混合效应模型 + 置换检验 + 效应量
```
